# GraveQuota

A co-op ragdoll gravedigging game for the browser. By day the hearse parks at the morgue: take each body in through the
hatch, read its delivery note, carry it from station to station — the registry desk writes its name tag, the dressing
table dresses them in the outfit on the note — lay them in the coffin that comes in from the stockroom, close the lid,
nail it shut if you can spare the nails, carry it to a grave and fill it in. By night the dead come for
the yard: whack them with your shovel, and fix the fence and traps in the morning with boards and nails.
Bodies slip out of your arms, a coffin is too heavy for one, and you can go limp and get carried by a friend.
How it was made: the whole working conversation with Claude, step by step, is at [`devlog/`](https://rokunin.github.io/xiombard-game/devlog/).
Play solo or host a room for friends. 3 AI helpers join, but for now they are off duty and just stand outside
(`?botwork` puts them to work, `?bots=0` leaves them home).

Built on [three.js](https://threejs.org/) + [cannon-es](https://github.com/pmndrs/cannon-es) physics, with peer-to-peer
co-op over WebRTC via [PeerJS](https://peerjs.com/). All visual assets are **generated by code** — GLSL shaders, noise and
procedural geometry — so we never buy store assets.

## Play

Host a game, share the 4-letter room code (or the invite link) with friends, they hit **Join**.

| Key | Action |
|---|---|
| WASD / Shift / Space | move / run / jump |
| Mouse (click to lock) or arrow keys | look |
| Click or E | grab / drop, whack with the shovel, take a body in at the hatch, write the name tag at the registry desk, open the outfit choice at the dressing table |
| 1–5 | pick an outfit while the choice is open |
| Right-click or Q | throw what you hold / cancel the outfit choice |
| F (hold) | work: dig, close a coffin lid, nail it shut, fill a grave, repair the fence or a trap, change a body's clothes |
| R | go limp (ragdoll) / get up |
| V | first-person / third-person view |

On phones and tablets on-screen controls appear automatically: stick on the left, drag on the right to look, buttons for grab, work, jump, throw and limp.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Every push to `main` builds with Vite and publishes to GitHub Pages via `.github/workflows/deploy.yml`.

## Layout

| Path | What it is |
|---|---|
| `src/main.js` | Menu, input, host/guest wiring, frame loop |
| `src/net.js` | PeerJS room hosting / joining |
| `src/sim/game.js` | Host-only physics simulation and game rules |
| `src/view/view.js`, `src/view/models.js` | Rendering and procedural models |
| `src/shared/` | Skeleton, level layout, seeded RNG (shared by host and guests) |
| `src/shaders/` | Toon lighting + outlines, sky, ground, noise |
| `src/audio.js` | Procedural sound effects |

## Asset rules

1. Prefer a shader or procedural mesh over a texture or model file.
2. If a file asset is unavoidable, it must be made by the team or CC0, and its source goes in `public/CREDITS.md`.
3. Anything both the physics and the visuals need (level layout, skeleton) lives in `src/shared/` — one source of truth.
