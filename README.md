# XIOMBARD: Night Shift

A co-op ragdoll gravedigging game for the browser. A truck keeps delivering bodies — unload it, put everyone in a coffin,
dig a grave and bury them. Bodies slip out of your hands, coffins flip over, and you can go limp and get carried by a friend.

Built on [three.js](https://threejs.org/) + [cannon-es](https://github.com/pmndrs/cannon-es) physics, with peer-to-peer
co-op over WebRTC via [PeerJS](https://peerjs.com/). All visual assets are **generated by code** — GLSL shaders, noise and
procedural geometry — so we never buy store assets.

## Play

**The job:** the hearse parks at the morgue. From inside, take each body in through the hatch, read its delivery note,
hang the right name tag, dress them in the outfit on the note, lay them in a coffin, close the lid, nail it shut if you
can spare the nails, drag it to a grave you dug and fill it in. Sloppy burials make restless graves.

Host a game, share the 4-letter room code (or the invite link) with friends, they hit **Join**.

| Key | Action |
|---|---|
| WASD / Shift / Space | move / run / jump |
| Mouse (click to lock) or arrow keys | look |
| Click or E | grab / drop, take a body through the hatch, take a name tag or outfit, use it on a body |
| Right-click or Q | throw what you hold / put a tag or outfit back |
| F (hold) | work: dig a grave, close a coffin lid, nail it shut, fill the grave |
| R | go limp (ragdoll) / get up |

On phones and tablets on-screen controls appear automatically: stick on the left, drag on the right to look, buttons for grab, dig, jump, throw and limp.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Every push to `main` builds with Vite and publishes to GitHub Pages via `.github/workflows/deploy.yml`.

## Layout

| Path | What it is |
|---|---|
| `src/main.js` | Menu, input, host/guest wiring, frame loop |
| `src/net.js` | PeerJS room hosting / joining |
| `src/sim/game.js` | Host-only physics simulation and game rules |
| `src/view/view.js`, `src/view/models.js` | Rendering and procedural models |
| `src/shared/` | Skeleton, level layout, seeded RNG (shared by host and guests) |
| `src/shaders/` | Toon lighting + outlines, sky, ground, noise |
| `src/audio.js` | Procedural sound effects |

## Asset rules

1. Prefer a shader or procedural mesh over a texture or model file.
2. If a file asset is unavoidable, it must be made by the team or CC0, and its source goes in `public/CREDITS.md`.
3. Anything both the physics and the visuals need (level layout, skeleton) lives in `src/shared/` — one source of truth.
