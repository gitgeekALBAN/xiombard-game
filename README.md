# XIOMBARD: Night Shift

A co-op ragdoll gravedigging game for the browser. By day the hearse parks at the morgue: take each body in through the
hatch, read its delivery note, hang the right name tag, dress them in the outfit on the note, lay them in a coffin,
close the lid, nail it shut if you can spare the nails, drag it to a grave and fill it in. By night the dead come for
the yard: whack them with your shovel, and fix the fence and traps in the morning with boards and nails.

Built on three.js, cannon-es physics and PeerJS peer-to-peer co-op. All visual assets are generated by code.
Play solo with 3 AI helpers or host a room for friends (4-letter code or invite link).

## Play

| Key | Action |
|---|---|
| WASD / Shift / Space | move / run / jump |
| Mouse (click to lock) or arrow keys, V | look, switch first/third person |
| Click or E | grab / drop, whack with the shovel, take a body at the hatch, take a name tag or outfit, use it on a body |
| Right-click or Q | throw what you hold / put a tag or outfit back |
| F (hold) | work: dig, close a coffin lid, nail it shut, fill a grave, repair the fence or a trap |
| R | go limp (ragdoll) / get up |

On phones and tablets on-screen controls appear automatically (stick, drag to look, GRAB / WORK / JUMP / THROW / LIMP).

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Every push to `main` builds with Vite and publishes to GitHub Pages via `.github/workflows/deploy.yml`.
