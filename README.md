# XIOMBARD

A browser game built on [three.js](https://threejs.org/). All visual assets are **generated by code** — GLSL shaders, noise and procedural geometry — so we never buy store assets.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Every push to `main` builds with Vite and publishes to GitHub Pages via `.github/workflows/deploy.yml`.

## Layout

| Path | What it is |
|---|---|
| `src/main.js` | Renderer, game loop, input, gameplay |
| `src/shaders/noise.glsl.js` | Shared GLSL noise / fbm |
| `src/shaders/sky.js` | Procedural sky dome (gradient, stars, nebula) |
| `src/shaders/terrain.js` | Noise-displaced terrain + CPU height function for collisions |
| `src/shaders/crystal.js` | Collectible crystal material (fresnel + animated bands) |

## Asset rules

1. Prefer a shader or procedural mesh over a texture or model file.
2. If a file asset is unavoidable, it must be made by the team or CC0, and its source goes in `public/CREDITS.md`.
3. GLSL that the CPU also needs (e.g. terrain height) must have a matching JS twin — keep both in sync.

## Contributing

Branch from `main`, open a pull request, get one review, merge. Pages redeploys automatically.
